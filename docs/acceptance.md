# 0.3.0 验收记录

验证日期：2026-09-11。开发机 macOS arm64 / Node.js 24.20.0；服务器 Debian 13 x86_64 / 独立 Node.js 24.20.0 / MediaMTX 1.21.0。

## 自动化验证

- `npm run check`：56 项测试通过，包括 16 项 Agent 核心、11 项 Agent 服务、3 项网关和原有 26 项直播回归；TypeScript 检查、Web/直播 API/Agent 构建及构建后真实 HTTP 闭环全部通过。
- 覆盖跨租户、公开秘密隔离、Origin/JSON/伪造 Cookie/大请求拒绝、注销重放与凭据撤销、代理信任与登录限流、本场资格重置、毫秒计时、暂停/隐藏/断线、并发红包金额守恒、重复领取、outbox 重跑、故障回滚、到期退款、事实依据、发布鉴权及断流失败处理。
- 构建后 HTTP 测试覆盖首页、观众路由、JS 资源、商家登录、房间、活动、心跳、领取、自动 worker、统计和源码不可公开读取。
- `npm audit --omit=dev --audit-level=high`：本次 0 个已知漏洞。首屏 JS gzip 约 91 KB；HLS 独立包按需加载，gzip 约 185 KB。HLS 体积提示不影响构建成功。

`forced-outbox-failure` 是主动注入的事务回滚用例。测试不调用真实支付。

## 浏览器验收

在实际服务器 HTTPS 站点使用桌面 Chromium 浏览器验证：

- 商家认证和带 `/studio/` 前缀的资源、观众链接正确。
- 真实 640×360 视频持续播放，`currentTime` 从 43 秒推进至 157 秒，`readyState=4`；有效观看累计到 2:29。暂停后画面时间和资格均保持不变。
- 观众提问成功，商家工作台收到同一问题。
- 添加待审核事实后不会立即用于提词；审核后建议显示该事实及依据。风险话术出现对应提示，提示不作为法律判断。
- 390×844 视口检查并修复横向溢出，最终页面宽度为 390 像素。它是桌面浏览器窄屏验证，不等同于真机移动端验证。
- 发现并修复 Chromium 原生 HLS 误报支持导致的播放中断，现优先采用 hls.js/MSE，保留原生回退。

## 独立 Agent 新版

- 独立进程、独立 SQLite、私有服务认证、租户隔离；Live Core 仅依赖 HTTP 契约，不读取提示词实现或模型密钥。
- 本地 16 项核心、11 项服务、3 项网关联调测试全部通过。模型 HTTP 测试使用模拟响应，没有真实模型调用。
- 自动化覆盖不可变版本、草稿/发布、任务输入快照、幂等与冲突、全局/租户任务上限、并行数、重启和关闭、反馈、证据撤回后的过期标记、服务错误脱敏。
- `/agent/latest` 只查询 `live` 任务；这类任务入队时必须采用已发布版本。较新的 `rehearsal` 草稿不会覆盖直播建议卡。任务读取、最新建议、创建请求的幂等重放响应和反馈响应都会重新核对当前场次、时间及引用事实撤回状态，不把旧建议重新变为有效。
- 服务器已新增独立 Agent 账号、数据库和服务，模型状态明确为未配置；原直播房间 6 条、事实 1 条、领取 1 条、账本 3 条在升级前后保持一致，原站首页/healthz/readyz 与新版入口均 HTTP 200。
- 已在公开测试站实际浏览器创建品牌风格，保存并查看不可变 V1/V2 草稿，发布 V2。输入“无出其右，会让所有人想起妈妈的味道”出现三项风险提示，模型未配置/本地规则状态显示清楚。

公开站点已实际完成 V2 试演并保存反馈；结果显示本地规则、四个执行阶段和事实出处。390×844 视口页面宽度为 390 像素，无横向溢出。最终服务更新及两次 Agent 重启后，2 个风格、3 个不可变版本、1 次试演、1 条反馈和品牌 V2 发布状态全部保留。

服务器额外验证：主动停止 Agent 后，原站首页/healthz/readyz、直播页面、直播健康接口及公开房间接口仍为 HTTP 200，Live 进程继续运行，媒体进程未被重启。恢复 Agent 后状态正常、模型仍未配置。两个服务账号均不能读取对方数据库或环境配置。此次更新后的即时可用内存约 900 MiB；它不是容量承诺。

## 小规模并发与故障隔离

运行 `npm run build && npm run concurrency:smoke` 可复跑独立 Live/Agent 进程的 HTTP 测试。本次默认 20 个并发匿名观众、400 次公开房间读取/观看心跳请求，本机测量 0 失败，交互请求 p95 为 10.29 ms。启动就绪重试单独统计，不算业务失败或延迟。这是当次 macOS 本地工作负载结果，不是公网或生产容量结论。

15 个随机红包共 10007 分，数量与金额守恒，重复请求保持幂等。主动停止测试 Agent 进程后，公开直播间读取、新心跳、已有红包领取与模拟 worker 仍继续工作。临时进程与数据库已清理。

该测试显式使用 `REQUIRE_PLAYBACK=false`，无真实视频、真实支付或线上压测；不能据此推导万人容量。真实媒体证据来自前述服务器链路测试。
