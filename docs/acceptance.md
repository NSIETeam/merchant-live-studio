# 0.2.0 验收记录

验证日期：2026-09-11。开发机 macOS arm64 / Node.js 24.20.0；服务器 Debian 13 x86_64 / 独立 Node.js 24.20.0 / MediaMTX 1.21.0。

## 自动化验证

- `npm run check`：26 项服务/API 回归、TypeScript 检查、Web/API 构建、构建后真实 HTTP 闭环全部通过。
- 覆盖跨租户、公开秘密隔离、Origin/JSON/伪造 Cookie/大请求拒绝、注销重放与凭据撤销、代理信任与登录限流、本场资格重置、毫秒计时、暂停/隐藏/断线、并发红包金额守恒、重复领取、outbox 重跑、故障回滚、到期退款、事实依据、发布鉴权及断流失败处理。
- 构建后 HTTP 测试覆盖首页、观众路由、JS 资源、商家登录、房间、活动、心跳、领取、自动 worker、统计和源码不可公开读取。
- `npm audit --omit=dev --audit-level=high`：本次 0 个已知漏洞。首屏 JS gzip 约 83 KB；HLS 独立包按需加载，gzip 约 185 KB。HLS 体积提示不影响构建成功。

`forced-outbox-failure` 是主动注入的事务回滚用例。测试不调用真实支付。

## 真实媒体和服务器

| 检查             | 实际结果                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 本机真实媒体链路 | MediaMTX + FFmpeg 的 10 项检查通过，包含 H.264/AAC 解码                                                                        |
| 服务器生产模式   | HTTPS 证书正常校验；禁止演示商家登录，实际访问密钥可登录                                                                       |
| 服务端严格资格   | 无信号、暂停、结束状态均不继续累计；领取需要新鲜有效心跳                                                                       |
| 服务器媒体/业务  | 8 组通过：错误密钥拒绝、正确源上线、HTTPS HLS 跳转/分片/音视频解码、资格、模拟领取幂等、账本、worker、分析、结束断流与重连拒绝 |
| 公网端到端       | 另一台独立服务器直接向公网 RTMP 发布，HTTPS HLS 下载 86,856 字节分片并解码 H.264/AAC，结束后确认源断开，3 组通过               |
| 数据持久化       | 应用和媒体服务重启后，全部业务表记录数保持一致                                                                                 |
| 既有服务         | 原站首页、healthz、readyz 在部署和测试后均为 HTTP 200                                                                          |

初始媒体测试的上行使用 SSH 隧道，公网验收另用独立主机直接发布，二者没有混称。本机直接公网 RTMP 曾握手失败，独立主机也超时；检查确认主机防火墙缺少 1935 入站规则。备份并仅添加该端口规则后，独立公网验收通过。

测试均使用清楚标注的合成画面和测试音。展示编码器最长运行 600 秒，验收后已停止，所有测试房间已结束；服务本身保留供继续测试。没有让合成画面伪装成真实商家直播。

## 浏览器验收

在实际服务器 HTTPS 站点使用桌面 Chromium 浏览器验证：

- 商家认证和带 `/studio/` 前缀的资源、观众链接正确。
- 真实 640×360 视频持续播放，`currentTime` 从 43 秒推进至 157 秒，`readyState=4`；有效观看累计到 2:29。暂停后画面时间和资格均保持不变。
- 观众提问成功，商家工作台收到同一问题。
- 添加待审核事实后不会立即用于提词；审核后建议显示该事实及依据。风险话术出现对应提示，提示不作为法律判断。
- 390×844 视口检查并修复横向溢出，最终页面宽度为 390 像素。它是桌面浏览器窄屏验证，不等同于真机移动端验证。
- 发现并修复 Chromium 原生 HLS 误报支持导致的播放中断，现优先采用 hls.js/MSE，保留原生回退。
