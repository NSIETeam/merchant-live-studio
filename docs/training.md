# 资料导入与场景评测

0.4.0 新增资料与评测能力，0.5.0 导航名改为“品牌与评测”。当前仍使用未配置模型的本地事实规则，支持资料准备、来源记录、提示词版本比较和人工反馈。这里的“评测”是有限测试题上的输出检查，不是完整讲稿审核、模型训练或法律合规证明。

## 商品资料

在商家选择的直播间内导入 UTF-8 CSV 或 JSON，也可直接粘贴。内容最多 24 KiB，每批 1–40 条。事实最多 400 字，依据最多 500 字；来源名称最多 120 字。模板中的虚构资料仅用于测试。

```csv
text,evidence
"虚构收纳盒容量为 500 毫升。","教学标签示例；不用于真实销售。"
```

```json
[
  {
    "text": "虚构收纳盒容量为 500 毫升。",
    "evidence": "教学标签示例；不用于真实销售。"
  }
]
```

预览不会写入数据库。确认导入时，在同一事务内新增事实并记录来源、内容摘要、时间和事实编号，全部新事实都为待审核。文件不能包含 `approved` 等额外字段，不能靠文件内容批准自己。格式错误或任一行不合要求时整批拒绝；账本式导入记录写入失败时，本批新增事实也会回滚。

以事实与依据的完整文本去重，包含本批内部重复和该房间已有资料。跳过重复项不改变原审核状态。相同房间、幂等键和请求可重放；同一键用于其他内容返回 409。重新预览后提交新内容应换一个键。

审核人在工作台逐条核对依据后确认或撤回。来源名称/网页链接是待核查的描述，不证明材料真实，服务不会自动下载或执行链接内容。本版不解析 PDF、Word、录屏或音频，也不采集真实商家资料进入演示库。原文件由业务方按授权保管，系统保留结构化摘录及内容摘要。

这个 CSV/JSON 导入入口仍将事实写入直播间备用资料。0.5.0 的“商品与课程”另有独立 SKU、类别与不可变证据版本，可被课程及直播复用；两个入口尚未自动迁移合并。绑定课程后，Agent 与场景评测使用课程商品依据，修改房间备用资料不会覆盖绑定版本。原始文件存储/解析和统一跨课程检索仍待完善。

## 主播和品牌样例

选定风格后，可导入最多 12 条情境/回应样例。需要填写来源，并声明素材为自己拥有或已获授权；该声明不替代实际授权材料。

导入将与所选最新提示词版本中的样例去重合并，合并后最多 12 条；超过上限返回错误，不静默截断。基准版本已经变化时返回 409，避免覆盖另一位编辑的改动。成功后保存新草稿和来源回执，原版本保持不变，已发布版本也不会自动切换。确需发布时仍在 Agent 工作台单独操作。

本功能仅储存和组织样例，不会学习模型权重。当前没有自动从录屏提取风格、声线克隆或实时转写。公开人物的风格名称与公开可读内容不能替代素材授权。

## 场景与版本比较

每组 1–8 道短题，可设置当前话术、观众问题、是否需引用事实、是否应保留答复、应出现的风险类别、结构化主张类型及不应输出的片段。内置八个压力场景只有主动点击才会载入，覆盖同义规避、步骤序号、情感联想、证据不足、事实引用、越权指令、治疗保证及虚构库存紧迫感；使用者可编辑后保存为不可变修订。它不是自动维护的行业规则库。

同名同房间题组每次保存产生新的不可变修订。一次选择 1–2 个不同的“风格 + 提示词版本”组合；每道题在相同商品事实快照下分别执行，总共最多 16 个任务。后台一次预留整个批次，容量不足时整批返回 429，不留下半个报告。复用现有持久队列、租户上限与并发限制；任务均属于试演，不会进入直播建议卡。

报告保存题组、提示词、商品和证据快照。检查针对证据引用一致性、题目设定的保留答复、风险类别、结构化主张类型和禁用片段；任务失败或配置模型后异常回退不会冒充模型评测通过。报告展开项显示策略版本、原句、所需依据和处理方向。风格和自然程度由人打分，系统不凭本地规则给出“品牌调教完成”的结论。

自动检查通过、人工评分可接受、提示词版本发布与讲稿审核发布是不同的动作。0.5.0 新增整篇文字讲稿编辑、规则检查、商家人工定稿与绑定播讲，详情见[内容工作台](content-workflow.md)；仍未实现独立审稿人或多级审批。

当前商品、事实或审核状态变化后，报告标为历史结果，停止新评分并要求重新评测。原评分只针对原快照。由于资料服务和 Agent 服务相互独立，跨服务读取与保存之间可能发生资料变化；返回报告仍再次核对过期状态，评分绝不触发内容发布。

## 验证和边界

新增自动化覆盖材料解析与事务回滚、授权声明、导入幂等、基准版本冲突、不可变题组、评测整批入队、租户隔离、重启、任务失败、依据撤回和人工评分。开发检查使用 `npm run check`，小规模并发故障隔离仍可用 `npm run concurrency:smoke`。

使用者提供的公司资料、客户信息、会议纪要和授权样例不应提交到公开源码仓库。导入的数据存放在各自部署的数据库中，默认网页演示仅使用明确标注的虚构内容。模型配置、真实支付和外部渠道均不因导入资料而启用。
