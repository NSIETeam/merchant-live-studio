# 播放器重连实测

2026-09-11，在独立本地 Live（18962）、MediaMTX（19989/19936）和独立 SQLite 上，通过 FFmpeg 发布 360×640、15fps 的合成测试视频。没有修改原服务器或本地常用预览的数据。

浏览器观众页实测：

1. 点击连接后，videoWidth=360、videoHeight=640、readyState=4、paused=false，currentTime=4.958518，截图可见真实解码画面。
2. 只停止测试发布进程后，页面显示“暂未收到直播信号”与“重新连接”；readyState=2。
3. 保持房间开放并恢复同一路推流，点击一次“重新连接”后播放恢复：readyState=4、paused=false、currentTime=5.560062，错误提示消失。
4. 390×844 浏览器视口中，播放器宽 390、高约 681.8，横向溢出 0；currentTime 继续推进至 24.702184。截图确认竖屏画面完整展示。

完成后结束独立测试房间、停止测试发布与服务、关闭测试页、恢复视口。本地常用预览 18959 保留。

这验证了本地 Chromium/MSE 的真实视频播放、断流提示及单次点击重连，不等于 Safari 原生 HLS、实体手机、微信或公网直播验收。此处测试视频含彩色条纹，产品界面配色未改为绿色。
