# 0.6.0 升级说明

0.6.0 汇总内容审改与长稿任务增量：版本逐段对照、绑定历史、成员角色、独立审核、集中待审、逐条建议采纳/拒绝、长稿大纲/分章生成、取消/续写与待审导入。真实模型保持待配置，真实微信支付仍未接入。此版本不是完整产品范围验收完成声明。

升级前备份 Live/Agent 数据库和环境配置。Live 迁移 v5–v8 增加不可变历史、独立审核、建议处置与生成导入记录；Agent 增加长稿任务与步骤记录。已有资料保留。生产环境旧的本人确认不能继续作为有效独立定稿使用，应保存新版本、由另一审核账号复核批准后重新绑定。旧稿原记录保留，不补造审核人或历史。

`MERCHANT_MEMBERSHIPS` 配置成员到管理员商家空间的映射，各账号必须拥有独立访问密钥，详见[团队审核](team-review.md)。模型未配置时长稿任务只等待，不生成模拟稿。每个 Agent 数据库只部署一个服务实例。

发布验证须分别记录：精确提交的 CI、构建清单及 SHA-256、数据迁移前后核对、线上多账号审改、未配置模型的诚实状态、公开观众数据边界。更换程序软链接失败时恢复旧程序和旧环境配置；数据库备份用于必要的人工恢复，不能用旧快照覆盖升级后的真实新增业务数据。
