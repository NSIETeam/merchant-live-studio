# 团队开户与密钥重置功能卡

主模块 platform/identity，配置与文件读取仍经 infrastructure，成员界面 web/shell。目标：管理员在本商家创建普通成员，首次发放高强度随机访问密钥；重置使旧密钥和旧会话失效；密钥只在操作成功时显示一次。不能创建第二管理员、跨商家迁移成员或重置其他商家/自己的管理员凭据。

兼容现有服务器配置账号，不迁移或删除原管理员。新账号凭据使用带独立随机盐的 scrypt，不保存原密钥；固定资源参数，禁止由存储字符串选择任意内存/计算量。凭据计算在异步线程池执行，入口需限流及并发保护，敏感响应 no-store，日志和事件不含密钥及校验值。

持久结构由 identity persistence 所有：账号归属、角色、凭据校验值、凭据版本及不可改写的创建/重置事件。角色变更沿用现有团队访问版本；重置原子更新凭据版本，认证每次验证版本。账号 ID 和身份归属来自服务端验证，不接受客户端指定 owner 权限。API 创建带幂等键，重置带凭据版本以防并发覆盖；丢失的一次性密钥不得通过列表重新读取，需显式再次重置。

失败策略：计算/落库失败不返回新密钥；数据库与审计同事务；进程重启后新账号可用，旧会话继续失效。备份包含校验值与版本，沿用私有数据库备份，不包含可恢复明文。回滚不能恢复已撤销凭据，发布需单独评估迁移与回滚。

验收：真正页面开户/登录、刷新不再显示密钥、重置旧密钥/旧会话失败、新密钥成功；权限、自身/管理员保护、并发/幂等、重启恢复、配置账号兼容。能力不等于真实身份核验。

## 实现进度

仅开始凭据基础：安全随机访问密钥、异步 scrypt 编码/校验、严格格式/长度约束。尚未接入账号表、登录、新 API 或页面，不代表开户功能已完成；后续必须完成上述整个用户流程后才统一发布。

### 账号存储基础（未接入应用启动）

新增 identity_accounts、identity_account_events，由 identity persistence 初始化并注册表归属；尚未由运行中的服务调用初始化，因此现有数据库不变。账号固定普通成员角色；重置按商家、账号及 expectedVersion 原子更新。账号写入和事件在同一事务，幂等键冲突导致整个写入回滚；列表及操作回执不返回校验值。新旧密钥仅在凭据测试中生成，没有改动服务器账号。

2026-09-11：3 项凭据/存储专项测试、架构门禁和类型检查通过。验证了重启后读取、重置旧值拒绝/新值接受、版本冲突、跨商家重置拒绝、重复事件时账号回滚及事件不可修改/删除。尚未证明 HTTP 登录、会话撤销、API 幂等响应或页面开户；这些仍需后续接入，当前不能合并发布为完整账号管理。

### 登录接入（本地，未发布）

应用创建 identity 时初始化新增表。新账号使用数据库校验值异步验证，最多 4 个并发校验；重置发生在计算期间会使本次旧凭据登录失败。会话凭据指纹包含账号、归属、角色、凭据版本与校验值，重置后旧会话在后续认证失效；没有调用服务器配置的明文比较来校验托管凭据。

托管账号只能依附仍存在的配置管理员（或明确演示空间）；管理员配置移除后托管账号不可登录。配置 ID 与托管 ID 冲突在启动时报错，不静默提升为管理员。现有配置账号仍走原登录路径。动态成员的独立审核判断经 identity 注入 Agent 现场读取，避免漏掉数据库成员。

新增真实 HTTP 登录测试覆盖：普通主播身份及租户、访问团队管理拒绝、密钥重置使旧登录与旧会话失败、新密钥成功、旧配置管理员登录兼容、管理员移除后的托管登录拒绝。成员列表/停用管理尚未合并托管账号，开户/重置 API 与界面仍待接入，不向正式环境发布此中间状态。

### 开户/重置接口及页面（本地，未发布）

新增管理员 POST /api/merchant/team/accounts 与 POST /api/merchant/team/accounts/:actorId/reset。请求键和操作指纹防止不同操作复用编号；重复成功操作只返回回执，不再次返回密钥。同键并行请求等待首个结果，CAS 重置与事件写入保持原子。每进程最多 4 个账号凭据生成任务，不无限排队。禁止在这些接口创建/重置配置账号、demo 或管理员自己。

团队列表合并托管普通账号并附 managed/credentialVersion；旧配置成员响应保持兼容。原角色与停用接口已支持新账号。HTTP 测试覆盖并行同键仅一次发放密钥、输入变更冲突、跨商家/成员越权、重置旧会话失效以及停用后拒绝登录。

TeamPanel 已接新增成员/重置表单，一次性密钥只保留在组件内存，手动隐藏或刷新后不再读取；不写 localStorage 或日志。需继续浏览器验证操作、请求失败后的恢复、手机排版和密钥隐藏，再完成整体合并与发布门禁。当前代码尚未发布，不能称线上账号管理已完成。
