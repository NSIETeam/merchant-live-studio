# 个人主页

登录后默认进入个人主页。主导航保留我的主页、商品与课程、直播现场；数据分析角色显示主页和数据复盘。表达、训练、互动和复盘通过主页入口进入，原有服务端权限保持不变。

默认显示常用功能与真实直播间列表。点击「自定义主页」可添加、隐藏、上下移动模块，选择常用快捷入口，或恢复默认。隐藏全部模块后仍可添加；底部「全部功能」始终保留有权限的入口。卡片不会虚构待办或经营指标。

布局通过 GET/PUT /api/merchant/home 保存在 Live 数据库的 home_preferences 表，按已认证的商家与账号组合隔离，跨浏览器和设备恢复。请求不能指定其他账号；返回和写入均按当前角色过滤/校验功能。版本号防止多个设备静默覆盖：过期写入返回 409，界面保留已保存布局并提示重新载入。失败不会显示保存成功。存储只包含模块、快捷入口标识和版本，不包含凭据。

旧的本浏览器 localStorage 布局可由用户主动导入，不自动覆盖已有账号布局。未成功读取账号布局时禁止编辑，避免网络问题时覆盖设置。

验证：142 项测试、类型检查、构建及 HTTP smoke；浏览器实际添加「品牌与评测」后重新载入确认保留；服务测试覆盖独立应用实例读取、同商家不同成员与跨商家隔离、过期写入、伪造账号、未授权功能和空布局。当前仅开发分支，未上线。
