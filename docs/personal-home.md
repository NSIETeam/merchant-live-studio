# 个人主页

登录后默认进入个人主页。主导航保留我的主页、商品与课程、直播现场；数据分析角色显示主页和数据复盘。表达、训练、互动和复盘通过主页入口进入，原有服务端权限保持不变。

默认显示常用功能与真实直播间列表。点击「自定义主页」可添加、隐藏、上下移动模块，或恢复默认。隐藏全部模块后仍可添加；底部「全部功能」始终保留有权限的入口。卡片不会虚构待办或经营指标。

布局按商家和账号组合键保存到当前浏览器 localStorage，不跨设备同步。存储不可用时明确提示本次修改仅在页面内有效。该存储只包含模块标识，不包含凭据或业务数据。

直播现场收起投诉、录像、数据和额外准备工具，保留开播准入、现场处置、画面和播讲操作。折叠不改变服务端准入和处置规则。

验证：141 项测试、类型检查、构建及 HTTP smoke；浏览器实际添加「品牌与评测」、上移并完成，再新开同源页面确认模块与顺序保留。响应式使用两列转单列规则，移动设备实测与跨账号浏览器隔离验收仍待补充。当前仅开发分支，未上线。
