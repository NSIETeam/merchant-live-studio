# 实时语音分段与直播 Agent 联动功能卡

本地后续候选已补充[媒体语音中继](speech-relay.md)：MediaMTX 在流上线时可启动独立进程，通过 FFmpeg 把内部 HLS 音频切片，再调用 OpenAI 音频转写兼容服务并回送本文定义的最终分段 webhook。中继同时报告当前场次的启动、流转、降级和停止状态，商家可区分媒体、转写/回送及超时故障；状态不向观众公开。该中继默认不启用，真实 ASR 模型、中文效果和现场延迟仍需配置后单独验收。

## 实现前填写

- **所属模块**：`live` 负责接收并保存当前场次的语音转写分段；`agent` 继续独立拥有提示词、运行和候选建议。装配层通过现有 `AgentBridge` 连接两者，不共享数据库或模型凭据。
- **用户验收场景**：已开播房间配置语音供应方后，供应方使用独立 Bearer 密钥提交最终转写分段；商家在直播页看到接入状态、最近片段时间和对应 Agent 处理状态，既有直播 Agent 卡继续展示候选建议。未配置供应方、未开播、鉴权失败或 Agent 离线时给出明确状态，直播、播放和互动不被阻断。本阶段提供供应方无关的 webhook 入口，不伪装浏览器麦克风监听，也不绑定具体 ASR 厂商。
- **接口变化**：新增 `POST /api/streams/speech/segments`，仅接受 JSON `{roomId,eventId,text,startedOffsetMs,endedOffsetMs,final}`，Bearer 鉴权，单段正文沿用 32 KiB 总限制、文本不超过 4000 字；相同场次和事件 ID 幂等返回同一记录，同键不同内容冲突。入口只完成原子保存与排队后返回，不等待 Agent 推理。新增商家接口 `GET /api/merchant/rooms/:id/speech/status`。跨 Agent 调用使用固定的服务端 `SPEECH_AGENT_PROFILE_ID` 和包含场次的摘要幂等键，沿用 5 秒超时；后台单实例有界处理，失败按安全状态延迟重试。
- **数据变化**：`live` 新增不可变表 `speech_segments` 保存最终短文本、供应方事件 ID、可信房间归属、场次开始时间及时间偏移；新增 `speech_analysis_jobs` 作为持久待处理队列，并新增 `speech_segment_analyses` 保存片段与 Agent 运行 ID 的不可变关联。迁移版本 21–22，表登记到所有权清单。文本属于直播内容记录，不写文件、不进入公开响应，随业务库备份；本阶段不实现自动删除，继续由平台留存声明明确执行状态，物理清理前必须处理争议保留和引用关系。
- **权限**：租户从服务端房间记录推导，正文不能指定租户。供应方只凭独立 `SPEECH_INGEST_SECRET` 调用写接口；商家状态接口沿用登录、角色和房间归属校验；观众接口不返回转写或 Agent 运行引用。密钥撤销后立即拒绝新请求。
- **失败处理**：禁用供应方返回 503，缺失或错误密钥返回 401，非 JSON 返回 415，非法字段返回 400，房间不存在或未直播返回 409/404。分段与待处理任务同一事务落库；Agent 未配置、超时、限流或错误不回滚分段，后台延迟重试。进程重启会把中断的处理任务恢复为待处理；Agent 端同一幂等键避免重复运行。非最终片段返回已忽略且不保存。停机最多等待当前有界任务完成，不在数据库关闭后继续写入。

## 随实现补充证据

- **流程结果**：最终分段经独立密钥写入当前直播场次，并在同一事务建立持久任务后立即返回；后台有界读取、退避重试、重启恢复，并用同场最近 8 段的受限窗口和稳定幂等键提交 Agent。商家状态接口重新读取到保存与处理结果；现场 Agent 卡显示接入、最近片段与处理状态。实机浏览器还发现并修复了直播状态切换后重复显示分享入口的问题。
- **基础检查**：当前工作区架构和数据所有权门禁通过；180 项业务测试通过；TypeScript、生产构建、HTTP 冒烟、`npm audit --omit=dev` 与 9 项部署脚本测试均通过。远端 CI 尚未运行。
- **专项验证**：`tests/live-speech.test.ts` 已覆盖错误鉴权、非直播房间、重复事件与冲突、租户隔离、公开响应不泄露、Agent 离线不阻断、同事件恢复分析、v21→v22 队列迁移、重启后持久化、慢 Agent 下立即应答、有界并发、跨段当前场次窗口、真实本地 Agent 高风险检测及弱密钥拒绝。真实浏览器验证 1280 和 390 像素宽度均无横向溢出、绿色界面或重复分享入口；移动端保持视频在前、Agent 卡在后。
- **阶段状态**：本地业务与界面验收通过，待提交和远端 CI。真实 ASR 供应方、模型服务和生产密钥待后续按服务商配置完成真实环境验收。
