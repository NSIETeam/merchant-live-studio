# 团队成员访问管理

管理员在个人主页底部展开「团队成员管理」，读取当前服务器配置的本商家成员、角色和可用状态。填写至少 5 个字的原因后可停用或恢复成员。列表和请求不包含密钥；新增账号、密钥配置和角色调整仍由服务器配置完成。

GET /api/merchant/team 和 PUT /api/merchant/team/:actorId 仅管理员可用。不能操作其他商家的成员、自己或管理员账号。写入携带状态版本，过期操作返回 409。停用时拒绝新登录，已有会话在下一次服务端认证时失效；恢复要求重新登录，旧会话仍然无效。不会主动终止已通过认证且执行中的请求，也不会停止正在推送的媒体流；现场停止须使用直播处置。

数据库迁移 v18：team_access 保存状态及访问版本，team_access_events 追加管理员、目标、原因、状态版本和时间，禁止更新或删除事件。改变服务器成员归属不清除访问版本和停用状态，避免旧会话意外恢复。

验证：144 项测试、构建、HTTP smoke 通过。服务测试覆盖停用登录、旧会话在恢复后仍无效、新登录成功、跨商家越权、自身账号保护、过期版本和记录不可改写。浏览器使用独立本地合成成员完成停用与恢复。未操作线上成员。

此模块提供访问停用管理，不构成真实身份认证；邀请开户、角色编辑及完整人员核验仍待实现/接入。

成员变更历史可在同一管理区域展开，按新到旧显示目标账号、停用/恢复、原因、操作人、版本与时间；每页 50 条，使用 before 游标继续查询。GET /api/merchant/team/events 仅本商家管理员可读，no-store；跨商家不返回记录。服务测试覆盖权限、游标和非法参数，浏览器读取上一轮合成停用/恢复两条记录并核对原因及顺序。全套 144 项测试、构建和 HTTP smoke 通过。
