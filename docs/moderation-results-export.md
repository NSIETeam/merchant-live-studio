# 处置执行历史与调取功能卡

主模块 live（处置、结果表均归 live）；web/review 展示，identity 显式授权路径。单次暂停曾失败再重试成功时，用户可逐页查看全部尝试，下载这次处置的全部执行结果，不再只见最后一次。

新增 GET rooms/:id/moderation/:actionId/results，按 id 倒序每页 50；before 为正整数。新增同路径 /export，下载 NDJSON：首行记录处置详情、生成时间和结果上界，后续每行一个执行结果。导出固定开始时的最大结果 ID，每批 100 行流式读取，不生成公共或服务器临时文件；新增尝试不混入这次快照。历史表不可修改，无数据库迁移或清理。

访问限管理员/审核/主播/编辑，与原处置只读权限一致；拒绝其他商家、错误房间或错误处置归属，匿名不可读，no-store。失败显示错误，不把部分页标为全部。下载期间数据库读取错误导致传输失败，客户端应重新下载；不可将残缺文件当成完整记录。

验收：多次失败与成功保留、跨房间/租户拒绝、分页边界、导出跨批次包含且仅包含固定上界结果，浏览器可展开历史和下载。继续遵循模块/存储规范，批量提交而非单独发布。
