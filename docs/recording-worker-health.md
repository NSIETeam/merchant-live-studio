# 录像登记运行状态功能卡

主模块 live，infrastructure 提供已有队列操作；web/live 展示。当前队列异常只写服务器日志，存储目录正常时界面可能隐藏全部提示。本次暴露进程内登记任务状态，帮助管理员发现处理器失败或长期未完成。

验收：配置后尚未运行显示 checking；完成一轮显示 available；队列读取/隔离失败显示 unavailable；任务启动后或最后成功后超过 60 秒没有完成显示 stalled；下一次成功自动恢复。直播不因此被自动关闭，不声称录制完整。

接口：已有管理员/审核角色 GET /api/merchant/recordings/health 新增 processor 枚举。仅返回状态，不泄露回执、错误内容、文件路径或其他租户数量。超时以服务时钟判断，轮询沿用 30 秒。无数据库迁移；WeakMap 随数据库对象回收，重启回到 checking。原回执、录像、重试和备份策略不变，无清理操作。

失败及恢复专项：使用真实不可读取的队列路径触发 worker 拒绝，再恢复目录并重新运行，验证 HTTP 状态变化；已有角色/租户测试继续适用。前端检查与类型检查完成后纳入后续批量发布，不单独部署。
