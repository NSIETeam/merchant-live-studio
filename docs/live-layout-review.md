## 修改

直播画面置于内容主区首位。桌面画面与辅助区约 3:1，取消顶部统计卡；辅助区通过提词器、观众提问、Agent 建议切换。手机顶部只保留简短品牌栏和房间选择，主导航固定到底部，画面先于控制、提词器与管理工具。录像、统计、投诉、准入检查和处置面板位于下方折叠区；服务端检查不因折叠而关闭。开播和结束操作仍在画面下方。

视频采用 contain 保持完整比例，不裁切竖屏或横屏内容。修复播放失败后点击重试仍残留提示、遮挡重新连接按钮的问题。
