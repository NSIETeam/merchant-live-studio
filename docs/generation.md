# 完整讲稿生成任务

本功能是尚未部署的开发增量。真实模型按用户安排稍后配置；本地合成响应只用于自动化测试，不代表真实文案质量或合规效果验收。

## 使用流程

在「商品与课程 → 讲稿与审改」展开「完整讲稿生成任务」，选择提示词方案、目标字数和章节数。任务固定使用该方案的最新保存版本；生成过程中修改提示词不会改变已有任务。目标为 500–12000 字、2–8 章，用于引导模型，不保证精确字数或直播时长。

Live 从已保存的课程与商品资料构建任务快照，浏览器不能提交替代商品依据。Agent 在自己的数据库保存输入、提示词快照、大纲和每个已完成章节，先生成大纲，再依次生成章节。章节正文使用模型输出，商品事实必须引用已核对事实 ID。有限结构检查只能校验引用存在，不证明整段语义、真实功效或适用范围。

- 模型未配置：任务保持「等待模型配置」，没有虚构章节。配置后由编辑点击「继续生成」。
- 失败：已完成章节保留，点击继续时从未完成步骤恢复，不重新生成前面章节。
- 取消：立即停止接纳当前请求的结果；已保存章节保留，可继续。
- 服务停止/重启：执行中的任务标为失败并保留检查点，需手动继续。排队任务可在启动后执行。
- 完成：仅表示全部章节返回且通过结构、引用和容量检查，仍为待审核草稿。

查看大纲与已生成章节后，可「导入为待审核草稿」。Live 再检查课程目标、受众、商品依据和原稿版本是否仍与任务一致；变化时拒绝覆盖。成功时在同一数据库事务中保存新稿、运行内容规则检查、记录导入凭据。重复导入返回原有版本。页面保留未保存输入，请在版本列表打开新稿。新稿不能继承已有稿件的批准，必须重新独立审核后再绑定直播间。

## 配置与接口

继续使用 `AGENT_MODEL_PROVIDER`、`AGENT_MODEL_ENDPOINT`、`AGENT_MODEL_MODEL`、`AGENT_MODEL_API_KEY`。默认 `grounded-rules` 不承担长稿生成。`openai-compatible` 使用完整 Chat Completions URL，要求 JSON 对象响应。`AGENT_GENERATION_TIMEOUT_MS` 为大纲/每章独立超时，默认 90000，最大 180000 毫秒；与直播短句的超时分开。

适配器拒绝重定向、超出 128 KiB 的响应、拒答、不完整输出及不符合 JSON 契约的结果。兼容协议要求 `finish_reason=stop`；`length` 表示达到输出限制，不能作为完整章节保存，参见 [OpenAI Chat API 文档](https://developers.openai.com/api/reference/resources/chat)。模型特有参数与实测质量需在选定服务后验证。

`GenerationProvider` 是独立可替换接口，负责单步模型调用。任务调度与存储不依赖供应商 SDK。现有 HTTP 适配器仅按配置访问模型端点；模型密钥留在 Agent 环境，不传给 Live、浏览器或任务记录。提供给模型的商品、提示词及样例按任务数据处理，不能授权新主张或改写系统边界。模型仅返回文稿，不返回隐藏推理。

Agent 服务接口均要求内部服务凭证与可信租户头：

| 方法 | 路径                                          | 用途                           |
| ---- | --------------------------------------------- | ------------------------------ |
| GET  | `/v1/generation/status`                       | 是否已配置及服务状态           |
| POST | `/v1/generation/jobs`                         | 保存快照并创建幂等任务         |
| GET  | `/v1/generation/jobs?courseId=...&before=...` | 课程任务摘要，每页 20 条       |
| GET  | `/v1/generation/jobs/:id`                     | 大纲、已完成章节、步骤尝试记录 |
| POST | `/v1/generation/jobs/:id/cancel`              | 取消任务                       |
| POST | `/v1/generation/jobs/:id/resume`              | 恢复失败、取消或等待配置任务   |

浏览器通过 `/api/merchant/content/courses/:id/generation` 列表/创建；`/:jobId` 查看结果，`/:jobId/cancel`、`/:jobId/resume`、`/:jobId/import` 操作。编辑/管理员可创建、取消、继续和导入；其他内容角色只读，分析账号不可访问。Live 先验证课程归属，Agent 再按租户隔离任务。内容人工编辑不依赖 Agent 在线。

## 存储与容量边界

Agent 使用 `agent_generation_jobs` 和不可变 `agent_generation_attempts`。输入快照禁止改写，每次步骤成功、失败、取消与继续记录状态和模型标识；不保存原始供应商错误和未验证输出。Live 迁移 v8 增加不可变 `content_generation_imports`，关联原任务快照、导入账号和保存版本。

长稿 worker 每次执行一个步骤，单并发，独立于现有短句 worker。排队/等待配置数量受现有 `AGENT_QUEUE_LIMIT` 与 `AGENT_TENANT_QUEUE_LIMIT` 控制，长稿与短句分别计数；因此这不是两个任务池合计的全局模型并发上限。当前每个 Agent 数据库只运行一个服务实例，尚未提供分布式租约、多实例恢复或成本结算。

每章最多 5 段、每段最多 1500 字，总计最多 40 段/12000 字。没有自动无限重试、超限静默截断或固定话术回退。更长讲稿需后续扩展容量与真实模型验收。尚未实现大纲人工修改后续写、章节单独重写、跨模型效果对比及真实主播风格质量验收。
