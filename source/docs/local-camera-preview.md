# 开播前本机画面检查

管理员及主播在未开播的“直播现场”展开“开播前检查摄像头”，手动点击开启后由浏览器申请摄像头权限。默认不申请权限，不申请麦克风、不录制、不发布媒体、不改变房间状态。

预览显示在主画面区域并标记“本机预览 · 未推流”。支持选择前置/默认或后置（设备支持时）；切换方向需先关闭预览。正式直播仍使用 OBS/手机推流工具及工作台推流配置，不能把看到本机画面等同于观众已能观看。

关闭预览、切换房间、离开直播现场、权限角色改变或房间进入 live 状态时停止持有的所有轨道。权限请求尚未返回就取消或离开时，稍后返回的流也会立即停止；过期请求不会覆盖较新的预览。

HTTPS 或 localhost 且浏览器支持 getUserMedia 才可使用。权限拒绝、没有设备、设备占用及播放失败有提示。手机/微信兼容性仍需真实设备测试。

2026-09-11：151 项测试、构建、HTTP smoke 通过；新增测试覆盖只请求视频、停止轨道、迟到授权与重复请求竞争、过期拒绝。浏览器检查 390px 无横向溢出、默认没有本机视频元素且需用户点击开启。未在本次自动工作中采集用户实际摄像头画面，因此硬件显示效果尚未验收。尚未发布服务器候选。
