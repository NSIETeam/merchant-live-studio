# 功能卡：商家会话失效收口

- **所属模块**：`identity` 提供 401 身份结果；前端共享请求层发布单一会话失效事件，商家壳层负责退出受保护工作区。直播、内容、Agent 等子模块不各自维护登录状态。
- **用户验收场景**：商家打开部署前保留的旧页面，凭据轮换、成员变更或会话撤销后任一受保护请求返回 401，界面立即回到登录页并显示“登录状态已失效，请重新登录”，不继续保留姓名、直播控制和半失效面板。403 只表示当前账号没有该项权限，不退出仍有效的会话。
- **接口变化**：HTTP 契约不变；共享请求层新增浏览器内 `kaopu:auth-required` 事件。
- **数据与权限**：不新增数据表、Cookie 或持久状态；前端事件不能建立身份，只清除当前界面的已登录状态。
- **失败与恢复**：网络错误和 5xx 保留当前工作区并允许重试；重新登录后按服务端新会话重新加载数据。
- **验收**：自动测试覆盖 401 触发退出事件、403 不触发；完整检查通过 225 项业务测试、架构与数据归属门禁、生产构建和 HTTP 冒烟。隔离浏览器先建立演示会话，再以新会话密钥重启服务；旧页面收到受保护请求 401 后立即返回登录页，显示失效说明。1280×720 页面横向溢出为 0。
