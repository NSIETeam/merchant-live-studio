# 平台信息、隐私与服务协议功能卡

归属 `platform/operations`，前端为公共信息页面。目标是在登录前和观众直播间内都能直接查看平台运营主体、平台投诉渠道、隐私联系人、隐私政策与服务协议；商家经营者公示继续由 `review` 独立管理，二者不能互相替代。

平台资料由服务器环境变量 `PLATFORM_COMPLIANCE` 提供 JSON，不进入公开仓库和商家可编辑数据库。字段包括运营主体企业名称、统一社会信用代码、地址、公开联系方式、平台投诉渠道、隐私联系人、政策生效日期，以及 HTTPS 隐私政策和服务协议链接。生产环境也允许暂时不配置，但公开页面和健康接口必须明确显示未配置，不能以“靠谱”、`NSIETeam` 或测试主体冒充真实运营者。

公开接口 `GET /api/platform/compliance` 无需登录，返回 `configured`、已校验的公开资料或 `null`，以及与当前软件行为一致的简要数据说明。响应禁止缓存，不返回环境变量原文、内部依据、访问密钥或服务器路径。登录页、工作台页脚和观众「经营者信息」均提供入口；独立 `/compliance` 页面可直接打开。

配置校验：企业名称、地址与各联系方式有长度边界；统一社会信用代码为 18 位大写字母或数字的格式检查；生效日期为真实日历日期；两份协议仅接受 HTTPS，或本机开发使用的 HTTP 地址。格式检查不联网验证主体登记、许可或协议内容，正式提审前仍需法务与运营核验。

验收：缺省状态不伪造资料；合法配置公开读取；非法代码、日期、非安全远程链接和额外字段拒绝启动；接口无缓存；登录页、观众信息抽屉及独立页面可达；桌面与 390 像素页面无横向溢出且不出现绿色界面。
