# 经营者公示资料

管理员或编辑在「商品与课程 → 经营者公示资料」填写直播间运营者、实际销售者的企业名称、统一社会信用代码、实际经营地址、公开联系方式、适用许可/备案说明，以及投诉售后联系方式。内部依据编号或受控材料位置单独保存，不向观众返回。

首轮仅支持企业资料。信用代码只做格式校验，不联网验证登记状态、代码校验位或许可真伪。资料必须由运营人员核验真实材料；不得将保存或内部复核等同主管部门许可。

保存生成不可改写的新版本，服务端比较原版本，防止覆盖他人修改。另一个审核/管理员账号核对后发布，保存者不能自审。新草稿不覆盖已公示内容。已发布或撤回的版本不能重新发布，需保存新版本重新复核。撤回只允许当前正在公示的版本，记录追加保留。

观众在直播页顶部点击「经营者信息」，无需登录、关注或领取奖励即可直接阅读。公开接口只返回已发布资料，不包含内部依据、编辑账号及审核意见。页面打开期间每 10 秒刷新；网络错误停止显示缓存资料并提示错误，接口禁止缓存。没有有效公示时明确提示待核实。

接口：

- GET /api/merchant/disclosure：最新草稿、当前公示状态、最近 100 次处理事件。
- POST /api/merchant/disclosure：previousVersion、data、evidenceReference；管理员/编辑。
- POST /api/merchant/disclosure/:version/review：action=publish/withdraw、note、acknowledged=true；管理员/审核。
- GET /api/public/rooms/:id/disclosure：该直播间商家的有效公示或 null，无须观看会话。

迁移 v13 新增不可改写的资料和事件表，保留旧资料。当前一份公示适用于商家空间全部直播间；多销售者逐商品映射、个人/个体工商户类型、到期提醒、主体实名动态核验仍待补。平台运营主体、隐私和协议使用独立公开配置，见 platform-compliance.md，不能用商家公示替代。后续本地增量已将有效公示接入生产开播准入，见 live-admission.md；不能把“填写了公示”视为具备上线条件。

验证：136 项全套测试、构建及 HTTP 冒烟通过；浏览器使用合成企业资料完成保存草稿、观众不可见、另一审核账号发布、观众读取和撤回后停止公示。内部依据未出现在公开结果中。尚未部署，也未核验任何真实企业资质。
