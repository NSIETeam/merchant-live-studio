# 功能卡：直播 Agent 结构化语义合规复核

## 实现前填写

- **所属模块**：主模块为 `agent`；`live` 只通过既有 Agent HTTP 网关取得候选建议和复核结果，`knowledge` 继续提供已审核事实快照，`review` 仍负责人工审核与发布决定。
- **用户验收场景**：主播或提示词编辑在“直播 Agent”输入当前话术后，界面按完整句子显示识别出的主张类型、处置级别、为什么需要复核、需要什么依据和应怎样处理。系统应把“第一”和“无出其右”归入同一类比较主张；把“第一步”识别为需要结合语境核对的序号；把“妈妈的味道”保留为主观情感表达而不虚构共同体验。评测台可一键载入八个固定压力场景，比较通用与品牌版本，并检查期望主张类型。范围不包含法律结论、真实模型调优或行业全量规则库。
- **接口变化**：`AgentResult` 兼容新增 `policyVersion`、`policyPack` 和 `claimDecisions`；旧持久结果可缺少这些字段。每个决定包含稳定规则编号、主张类型、级别、命中表达、所在语句、判断说明、所需依据和处理方向。评测场景的 `expect.decisionTypes` 为可选字段，旧场景保持有效。既有 `/v1/check`、任务和评测接口路径不变，无跨模块重试或幂等变化。
- **数据变化**：无数据库和文件变化。新评测报告继续把结构化结果保存于 Agent 自有运行结果 JSON；旧记录按兼容字段读取。政策定义是源码版本资产，版本号随结果保存，便于回归追溯。
- **权限**：沿用既有商家会话、可信租户网关、Agent 服务令牌和房间归属校验。浏览器不能提交政策、模型地址或证据；结构化决定不增加写权限，也不能批准事实或发布内容。
- **失败处理**：规则未命中时明确保留“有限复核、不能证明合规”的提示；无法判断语境时给人工复核而不自动放行。模型未配置、超时或结构错误仍回退本地受控编排，结构化复核由本地确定性政策执行。旧报告缺少结构化字段时界面继续显示原风险提醒。

依据：[模块开发规范](module-development.md)、[Agent 说明](agent.md)、[资料与评测](training.md)。政策设计参考市场监管总局《广告绝对化用语执法指南》《互联网广告管理办法》《广告引证内容执法指南》及现行《广告法》；系统只提供风险分流和证据提醒，不作执法认定。

## 随实现补充证据

- **流程结果**：已完成确定性语义政策层、直播 Agent 接口、快速复核、评测台和八个压力场景的贯通。实际浏览器评测为 8/8 场景通过；报告明确显示 `本地规则生成 · cn-live-claims-2026.1`，不冒充真实模型结论。
- **基础检查**：`npm run check` 通过，含架构与数据归属检查、185 项业务测试、类型检查、生产构建及 HTTP 冒烟；`npm audit --omit=dev --audit-level=high` 为 0 个漏洞；部署脚本 9 项测试通过。
- **专项验证**：Agent 核心、评测服务和 Live 网关专项共 33 项测试通过。浏览器验证桌面 1280×900 与移动端 390×844 均无横向溢出，页面未使用绿色主界面；压力场景报告能展开查看主张类型、证据要求与处理方向。浏览器联调曾发现 Live 网关未接收 `decisionTypes`，现已补齐跨服务契约并加入回归测试。
- **阶段状态**：本批功能可发布。真实模型、真实 ASR、行业人工标注集及执业审核仍为独立验收项。
