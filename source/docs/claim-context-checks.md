# 主张检查：语境与字符变体

2026-09-11 开发分支更新：

- Agent 风险扫描与讲稿预检共用 scanner-only 的 NFKC、格式控制字符移除与汉字之间空格/制表符归一化。原文、商品依据及传给模型的材料保持原样；提示中的命中片段可能是归一化形式。
- “无出其右”“无 出 其 右”、零宽字符变体和全角百分比等不再因为字符形式不同而漏过已有检查。
- Agent 对明确带分隔符的“第一步：”“第一章：”提示核对序号语境，不直接报高风险优越性承诺。同一句中的“行业第一”“无出其右”仍保持高风险，不能用步骤标题包裹承诺来放行。
- 讲稿检查版本更新为 `kaopu-content-rules-2`。既有版本检查机制会将旧规则下的稿件标为 stale，需重新检查与审核后使用。

市场监管总局《广告绝对化用语执法指南》要求结合广告内容、具体语境整体判断，不能仅凭单个词机械判定。依据：[官方发布说明](https://www.samr.gov.cn/xw/zj/art/2023/art_472da8e738c241449174210e44424a20.html)。本实现只提供有限规则预检，不作法律许可判断；“review”也不代表合法、真实或已批准。真实模型语义效果仍未配置或验收。

自动测试覆盖字符变体、原文保持不变、序号提示、序号与优越性承诺混合场景，及既有规则变化后旧稿失效。所有测试、构建、HTTP smoke 通过；改动尚未发布服务器。
